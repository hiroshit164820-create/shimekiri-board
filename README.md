# 会社業務のしめきりボード

会社ごとの締切と「つぎに動くのはだれか」を、スマホで見るためのボードです。

**公開ページ → https://hiroshit164820-create.github.io/shimekiri-board/**

## 何をする道具か

会社ごとに、抱えている業務（補助金の申請、採用、ホームページ更新など）と締切をならべます。
ふつうの予定表とちがうのは、**「つぎに動くのはこちらか、お客様か」がひと目で分かる**ことです。

```
会社 → 業務 → 予定 → タスク
```

- 色は2つのことを答えます。カード全体の色が「つぎに動くのはだれか」、左はしの帯が「いつまでにやるか」
- 会社は、検索するか「すべての会社を見る」を押すまで出ません
- パソコンで開くと、横が月・縦が業務の表に切り替わります

## このページでできないこと

**変更は保存されません。** 画面の右上に「お試し表示」と出ます。

保存の仕組みは配布元（claude.ai）の枠から渡されるもので、この公開ページには入っていません。
ここは**動きを見てもらうための置き場**です。中に出ている会社名（A社・B社・C社）はサンプルです。

## 中身

`index.html` の1枚だけで動きます。外部の通信はなく、
読み込むのは Google Fonts（Zen Kaku Gothic New / Noto Sans JP）だけです。

## 作りかた

元のファイルは別のフォルダで管理しています（`shimekiri-board/`）。

```
python build.py       # board_src.html にデータを入れて組む
python build_site.py  # 公開用の index.html を書き出す
```
